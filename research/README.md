# البحث العلمي ومهارات البحث

موارد تساعد المتعلمين والمعلمين على تنمية مهارات البحث والتفكير الناقد والتوثيق.

## أفكار للمحتوى

- تحديد المشكلة وصياغة الأسئلة والأهداف.
- البحث عن المصادر وتقييم موثوقيتها.
- التمييز بين الرأي والدليل والتحقق من الادعاءات.
- التوثيق العلمي وتجنب الانتحال.
- الاستخدام المسؤول للذكاء الاصطناعي في مراحل البحث.

يجب التمييز بوضوح بين المصادر الأولية والثانوية، وعدم اختلاق المراجع أو بيانات النشر.
