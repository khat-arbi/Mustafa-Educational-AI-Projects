# استراتيجيات التدريس والموارد التعليمية

يضم هذا القسم خططًا وأنشطة وأدوات للتدريس النشط والتعلم التعاوني والتقويم من أجل التعلم.

## أفكار للمحتوى

- التعلم القائم على المشروعات وحل المشكلات.
- التعلم التعاوني والتعلم المقلوب.
- استراتيجيات تنمية التفكير والإبداع.
- أدوات التقويم القبلي والتكويني والختامي.
- موارد مهارات القرن الحادي والعشرين.

أرفق مع كل مورد الهدف والفئة المستهدفة والزمن المقترح وخطوات التنفيذ وأداة التقويم.
