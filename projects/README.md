# المشروعات التعليمية

هذا المجلد مخصص للمشروعات والتطبيقات التعليمية المكتملة أو قيد التطوير.

## بنية مقترحة لكل مشروع

```text
project-name/
├── README.md
├── src/              # الشفرة المصدرية عند وجودها
├── assets/           # ملفات الوسائط المسموح بنشرها
├── examples/         # أمثلة الاستخدام
└── tests/            # الاختبارات عند الحاجة
```

ينبغي أن يشرح ملف المشروع المشكلة التي يعالجها، والجمهور المستهدف، والمتطلبات، وخطوات التشغيل، وحدود الاستخدام، والترخيص.
