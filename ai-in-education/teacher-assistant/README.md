# المساعد الذكي للمعلم

**إصدار أولي: حزمة مطالبات وقوالب عملية (Prompt Toolkit)**

مشروع مساعد يساند المعلم في تحويل موضوع الدرس إلى خطة تدريس وأنشطة متدرجة وأدوات تقويم، مع إبقاء القرار التربوي والمراجعة النهائية بيد المعلم.

## 1. ماذا يقدم؟

- تحليل موضوع الدرس وتحديد نواتج تعلم قابلة للملاحظة والقياس.
- اقتراح خطة درس متسقة مع المرحلة والزمن والإمكانات.
- تصميم أنشطة متنوعة تراعي الفروق الفردية.
- إعداد أسئلة تقويم قبلي وتكويني وختامي مع مفاتيح إجابة مقترحة.
- بناء سلم تقدير واضح لمهام الأداء.
- مراجعة الخطة للتحقق من الاتساق والدقة وإمكانية التنفيذ.

## 2. الملفات

- `prompts/lesson-planner.md`: مطالبة إعداد خطة الدرس.
- `prompts/activity-designer.md`: مطالبة تصميم الأنشطة المتدرجة.
- `prompts/assessment-builder.md`: مطالبة بناء التقويم وسلالم التقدير.
- `templates/lesson-plan.md`: قالب توثيق خطة الدرس.
- `templates/assessment-rubric.md`: قالب سلم تقدير.
- `examples/arabic-reading-lesson.md`: مثال تطبيقي في الفهم القرائي.
- `SAFETY.md`: ضوابط الاستخدام والتحقق وحماية البيانات.

## 3. طريقة الاستخدام السريعة

1. افتح ملف المطالبة المناسب وانسخ نصه إلى أداة الذكاء الاصطناعي التي تستخدمها.
2. استبدل الحقول بين الأقواس ببيانات الدرس غير الحساسة.
3. اطلب من الأداة إظهار الافتراضات والأسئلة التي تحتاج إلى توضيح بدل اختلاق معلومات.
4. راجع الناتج في ضوء المنهج المعتمد ومستوى المتعلمين ووقت الحصة.
5. عدّل الناتج ثم وثّق النسخة النهائية في قالب الخطة.

## 4. المدخلات المطلوبة

- المادة والصف أو المرحلة.
- موضوع الدرس وموقعه في الوحدة.
- زمن الحصة.
- نواتج التعلم أو المهارات المستهدفة إن كانت محددة.
- خصائص عامة للفصل واحتياجات التعلم دون أسماء أو بيانات شخصية.
- الموارد المتاحة والقيود الواقعية.

## 5. مخرجات متوقعة

خطة تتضمن التهيئة، والنواتج، وتسلسل إجراءات التدريس، وأنشطة المتعلم، والزمن، والموارد، والتمايز، والتقويم، والغلق، والواجب أو الامتداد التعليمي.

## 6. حدود المشروع

هذه النسخة حزمة مطالبات وقوالب وليست تطبيقًا برمجيًا مستقلًا أو نظامًا متصلًا بمنصة مدرسية. لا تضمن أدوات الذكاء الاصطناعي صحة كل معلومة أو توافق كل اقتراح مع المنهج؛ لذلك يلزم التحقق البشري قبل الاستخدام.

## 7. التطوير القادم

- إضافة نماذج جاهزة لمواد وصفوف مختلفة.
- اختبار جودة المخرجات باستخدام سيناريوهات صفية متنوعة.
- إضافة واجهة استخدام بعد تحديد المتطلبات وتجربة الحزمة.
- توثيق الإصدارات وملاحظات التحسين.
