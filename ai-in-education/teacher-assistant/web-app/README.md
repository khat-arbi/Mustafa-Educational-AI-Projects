# مِداد | مساعد المعلم التربوي — نسخة أولية 0.1

تطبيق ويب عربي بسيط (RTL) يساعد المعلم على إعداد مسودة أولية لخطة الدرس، وأنشطة متدرجة، وأفكار للتقويم.

## التشغيل
1. نزّل مجلد web-app أو افتح المستودع على GitHub.
2. افتح ملف index.html في متصفح حديث.
3. أدخل الصف والمادة وموضوع الدرس والزمن، ثم اضغط «إنشاء تصور الدرس».
4. حرّر النص الناتج، ثم انسخه أو اطبعه.

لا يحتاج التطبيق إلى تثبيت حزم أو خادم أو مفتاح API. يمكن نشر المجلد كما هو على GitHub Pages أو أي استضافة ملفات ثابتة.

## ما الذي تتضمنه النسخة؟
- واجهة عربية متجاوبة واتجاه كتابة من اليمين إلى اليسار.
- نموذج بيانات للدرس مع مثال تعبئة سريع.
- تصور زمني للدرس، ونواتج تعلم، وتهيئة، وبناء تعلم.
- أنشطة متدرجة: دعم، أساسي، إثراء.
- أفكار للتقويم البنائي والختامي وأسئلة مقترحة.
- مساحة تحرير مع النسخ والطباعة.

## حدود النسخة الحالية
- التوليد محلي قائم على قوالب JavaScript ثابتة؛ لا يوجد اتصال فعلي بنموذج ذكاء اصطناعي.
- لا يتصل التطبيق بكتاب مدرسي أو قاعدة بيانات مناهج، ولا يضمن مطابقة المحتوى لتوزيع منهج بعينه.
- الأسئلة عامة، وقد لا تكون لها إجابة نموذجية دقيقة دون إدخال نص الدرس ومحتواه.
- لا توجد قاعدة بيانات أو حسابات مستخدمين أو تخزين لمدخلات المعلم.

## الخصوصية والسلامة
- لا تُدخل أسماء الطلاب أو أرقامهم أو أي بيانات شخصية.
- راجع كل ناتج علميًا وتربويًا قبل استخدامه.
- عدّل الأنشطة لتناسب احتياجات المتعلمين وإمكانات المدرسة.
- لا تستخدم المسودة وحدها لاتخاذ قرارات تقويمية عالية الأثر.

## الملفات
- index.html: بنية الواجهة.
- styles.css: التنسيق والتصميم المتجاوب.
- app.js: منطق إنشاء المسودة والتعامل مع الأزرار.

## التطوير المقترح
المرحلة التالية يمكن أن تضيف ربطًا آمنًا بخدمة ذكاء اصطناعي عبر خادم خلفي، وقوالب تخصصية لكل مادة، وبنك أسئلة مرتبطًا بنص الدرس، وتصديرًا منسقًا إلى PDF/DOCX. يجب حفظ مفاتيح الخدمة على الخادم لا داخل ملفات المتصفح.
