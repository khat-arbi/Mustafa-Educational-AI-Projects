# الذكاء الاصطناعي في التعليم

يضم هذا القسم نماذج وأنشطة وأدوات تساعد المعلم على توظيف الذكاء الاصطناعي بصورة تربوية مسؤولة.

## أفكار للمحتوى

- تخطيط الدروس وصياغة نواتج التعلم.
- إعداد أنشطة متدرجة تراعي الفروق الفردية.
- بناء rubrics وأدوات تقويم وتغذية راجعة.
- تصميم مساعدات تعليمية ومحادثات تدريبية.
- تنمية الوعي بالتحيز والخصوصية والتحقق من المخرجات.
